# BloodSync – Blood Donation & Hospital Management Backend 🩸

BloodSync is a backend-based blood donation and hospital management system developed using Java, Spring Boot, Spring Data JPA, MySQL, and REST APIs. The system manages donors, hospitals, blood requests, inventory, and admin operations through a structured backend architecture.

## 🚀 Features

* Donor registration and profile management
* Hospital registration and request management
* Blood request creation and status tracking
* Admin approval/rejection workflow
* Blood inventory management
* Role-based backend API structure
* CRUD operations for donors, hospitals, and requests
* RESTful API integration for frontend connectivity

## 🛠️ Tech Stack

* Backend: Java, Spring Boot
* Database: MySQL
* ORM: Spring Data JPA / Hibernate
* API: REST APIs
* Tools: Maven, Postman, Git, GitHub
* IDE: IntelliJ IDEA / Spring Tool Suite

## 🔧 Modules Included

* Donor Management
* Hospital Management
* Blood Request Management
* Admin Dashboard APIs
* Inventory Management
* Authentication Module
